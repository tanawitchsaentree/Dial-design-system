# dial

dial is the face of a household appliance, drawn on a screen. People at home use it on a phone or a laptop to turn the heating down, dim a lamp, see whether the washer is done, or skip a track. They look at it for a few seconds and then go back to their lives, so every unit (a card, a sheet, a screen) behaves like one small appliance in the Braun / Ulm tradition: a warm-white matte plastic body, one display that says the state, a perforated grille where something is happening, and one orange part, the control you turn or press. The rest is grey ink on plastic. Its source is Dieter Rams' ten principles and "Weniger, aber besser": less, but better. It must never become a retro costume (fake logos, fake plastic grain, grime), never use the Braun name or mark (dial has its own wordmark), never spread orange across the screen, never set light grey on light grey below 4.5:1, and never swell into a bloated round toy.

Generated by kiln (`tooling/kiln/design-md.mjs`) from the tokens, the concept, every component's reasons and the decision log. Edit those, never this file.

## How to use this system

Install `dial-react` and `dial-tokens`, import `dial-react/all.css` once, and build from the components below before writing new ones. Use semantic tokens (`var(--ds-…)`) and never a raw colour, size or duration. Other platforms read the same names: `dial-tokens/tailwind`, `/swift`, `/kotlin`, `/dart` and `/figma`.

This file cannot check your work, so keep to what kiln would have measured:

- body text at 4.5:1 or more in every theme, over every backdrop the screen can show
- one loud element per surface, and no colour that carries meaning alone
- every control reachable and visible by keyboard, with its focus ring
- spacing, corners and motion only from the tokens, and nested corners that follow the outer one

## Principles

- **P1 One loud thing per unit.** (Rams: good design is unobtrusive.) Each unit has exactly one primary control, and only that control
- **P2 The display tells the state.** (Rams: good design makes a product understandable.) Every unit has one window that says what the
- **P3 Parts behave like parts.** (Rams: good design is honest; it is thorough down to the last detail.) A control in dial is a key,
- **P4 Holes are information.** (Rams: good design is as little design as possible.) A perforated grille appears only where it
- **P5 Type is a label, not a voice.** (Rams: good design is aesthetic only through usefulness.) One grotesk, few sizes. The wordmark sits
- **P6 Lasts, so it stays still.** (Rams: good design is long-lasting; it is environmentally friendly.) dial does not chase attention.
