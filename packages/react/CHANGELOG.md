# dial-react changelog

One line per change, `- Component: what changed`, under `## <version> (<YYYY-MM-DD>)`. The docs read this file for every component's history.

- Button: First release: a capsule key with kind key or primary and sizes md and lg.
- Switch: First release: a slide switch with a cap in a recessed groove, printed position words and a lamp; role switch, Space and Enter throw it.
- Text: First release: printing on the case, five sizes, two inks, regular and medium, tabular figures.
- Heading: First release: h1 to h4 at the display, headline, title and emphasis sizes, medium weight, primary ink.
- IconButton: First release: a round 44px key with a printed icon, a required label as its accessible name, kind key or primary, size md or lg.
- Checkbox: First release: a small square key over a native checkbox, an ink tick when on and a dash when mixed, the label printed beside it.
- Display: First release: the recessed state window, LCD 7-segment or OLED text, a polite live region.
- Grille: First release: a perforated field whose recessed holes are a level meter, role meter with a required label.
- Slider: First release: a fader with a plastic cap in a recessed groove, a printed ruler, detents and the material's spring.
- Rotary: First release: the knob, a disc with one index line over a tick ring of detents across 270 degrees, primary (orange) or key.
