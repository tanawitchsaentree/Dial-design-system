Four raised capsule keys like a radio's station keys; the current one latches low. Four raised keys compete with each unit's one loud control, and a link is not a key that latches.

A recessed LCD strip with the four words; the current word is lit, the rest ghosted. A display tells the device's state; using one as navigation gives every screen a second display and ghost words read as disabled.
