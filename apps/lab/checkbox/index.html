Checkbox — three ways a small square key shows it is on

Same matte ABS, same light, same spring, travel 3px. The mechanism is a key in all three: press drops it and the spring returns it. What changes is how the on state is shown. The mark is printing ink, never orange. Off and on must differ in shape, not only in colour.

A · tick printed on the key

The key always stands at its height; a 2px ink tick appears on its face. A dash shows mixed.

B · key with a lamp beside it

The appliance key with an indicator: a hollow ring when off, a filled dot when on. The lamp is 8px, so the state rides on a very small shape.

C · latching key

Like old radio keys that lock down: an on key stays pressed and flat. Flat is also how disabled looks, and a held-down key can no longer show a press.
